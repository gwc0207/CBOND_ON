# CBOND_ON 因子开发规则（兼容入口）

本文件保留为旧链接的兼容入口，不再包含独立的执行规则。

请使用 [因子工程治理规则](因子工程治理规则.md) 作为唯一因子工程规范，并遵循：

```text
上游数据 -> 公共 panel -> label -> canonical factor table -> 模型输入 -> 回测或实盘产物
```

正常读写只允许三张正式表：

```text
D:/cbond_on/factor_store/live
D:/cbond_on/factor_store/experiment
D:/cbond_on/factor_store/factor_library/<family>
```

普通代码不得把自由 `factor_data_root`、旧 `factor_data` 或单个 parquet 当作因子结果通路；历史数据只可在明示的迁移、审计或 no-DB 临时 staging 中使用。
